# Claims Client

Optional Fabric client mod for the Claims Paper plugin and Reports' Snake mini-game. Version **1.31.2** targets Minecraft **26.3**, Fabric Loader 0.19.5+, Fabric API 0.162.0+26.3 and Java 25.

Install the JAR from the [Releases page](https://github.com/Tobias30yt/Claims-Client/releases) into the Minecraft `mods` folder. The Claims server plugin is still required for Homes and Claims screens. Use **Controls → Claims → Open Claims menu** to view or change the default O keybind. The mod announces optional support to Reports; `/snake` then opens an in-game vanilla-style Snake screen. Players without the mod keep using Reports' chest GUI.

Build from source with `gradlew.bat --offline jar` (or `./gradlew --offline jar`) using Java 25. The output is `build/libs/Claims-Client-1.31.2.jar`.
